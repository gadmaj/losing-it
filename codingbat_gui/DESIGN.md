# Physics practice interface

Pinned reference: the user's request for a very basic CodingBat-like GUI.
Mode: Operate. A restrained document-and-editor layout, with a numbered problem
list, the actual exercise text, a Python/C++ editor, one Run button, and output.
A compact practice-set selector switches between HW8 and the two midterms.
Keep source diagrams visible with their questions and the original PDF accessible.

Use white paper, dark text, a muted green action color, thin neutral rules,
system sans-serif for prose, and the installed monospace font for actual code.
No marketing sections, imagery, animation, fake IDE chrome, or framework UI.
On narrow screens, replace the problem rail with a select menu. Keep code
errors readable and preserve source indentation.
